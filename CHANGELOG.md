# Журнал изменений — AgentClinic

Все заметные изменения проекта. Разделы — по датам коммитов, новые сверху.

## 2026-09-28

- Фаза 1 «Агенты»: E2E-сценарий на Playwright (список → профиль, пустая форма, регистрация → профиль → список), обновлены `README.md`, `tech-stack.md`, `roadmap.md` и решения в `requirements.md`
- Регистрация агента: `POST /api/agents` с валидацией (400 и `errors` по полям, сообщения на русском) и уникальностью имени без учёта регистра, в том числе для кириллицы (409); страница `/agents/new` с формой, после успеха открывается профиль нового агента (f76f41a)
- Профиль агента: `GET /api/agents/{id}` (404 для несуществующего), страница `/agents/[id]` с датой регистрации на русском; ошибки API отдаются в формате ProblemDetail (RFC 9457) (9191e61)
- Страница `/agents` со списком агентов и страницей ошибки при недоступном бэкенде; «Агенты» в шапке стали ссылкой с подсветкой текущего раздела (edb82c6)
- Контракт API: springdoc-openapi, снимок `openapi/openapi.json` с тестом на актуальность, TypeScript-типы из `openapi-typescript` (`npm run api:generate`) с проверкой в CI (bd269a9)
- Сущность `Agent`: миграции `V2__create_agent.sql` и `V3__seed_agents.sql` (шесть агентов-пациентов), `GET /api/agents` возвращает агентов по имени (f9be302)
- Добавлена спецификация фазы 1: требования, план и критерии готовности (cef7a50)
- Бэкенд перенесён в `backend/` и переведён на Spring Boot 4 (Java 21, Maven Wrapper); эндпоинт `GET /api/health` отвечает `{"status":"ok"}` (5a78a70)
- Подключены SQLite, Spring Data JPA и Flyway: база `backend/data/agentclinic.db` создаётся при старте, применяется пустая миграция `V1__init.sql`; тесты работают на временной БД (8f3ce41)
- Добавлен фронтенд `frontend/` на Next.js 16 (TypeScript strict, Tailwind 4) со стартовой страницей «Добро пожаловать в AgentClinic» (e397525)
- Главная страница показывает статус бэкенда («проверяем…», «ok», «недоступен»); запросы `/api/*` проксируются на бэкенд через `BACKEND_URL` (702037f)
- Подключён shadcn/ui, добавлен общий layout: шапка с навигацией («Главная», неактивные «Агенты» и «Недуги») и футер (60a5107)
- Настроены проверки: ESLint и Prettier, Vitest-тесты фронтенда, Playwright-smoke с настоящими бэкендом и фронтендом (в том числе ширина 375 и 1280 px), GitHub Actions с job `backend`, `frontend` и `e2e` (e397525, 4e460e1, 17ad2aa)
- `README.md` описывает требования, запуск в двух терминалах (для Windows — `.\mvnw.cmd`) и все тестовые команды; обновлены `specs/tech-stack.md` и `specs/roadmap.md`, решения по ходу реализации записаны в `requirements.md` (4e460e1, e39e401)
- Добавлена спецификация фазы 0: требования, план и критерии готовности (1de72be)
- Добавлена конституция проекта: миссия, технологический стек и roadmap (a5b9c36)
- Добавлен `CLAUDE.md` с правилами работы ассистента в проекте (0c7249d)
- Создан исходный Maven-проект (ce761e6)
