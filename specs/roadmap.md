# Roadmap AgentClinic

Каждый этап — **один PR с результатом, который можно показать** (в браузере, через
API или в тестах). Этапы идут строго по порядку: следующий опирается на предыдущий.
Цель первой версии: **запись на приём работает от начала до конца** (фаза 5).

## Фаза 0. Скелет

- [x] **0.1** Перенести Maven-проект в `backend/`, подключить Spring Boot;
      `GET /api/health` возвращает `ok`.
- [x] **0.2** Подключить SQLite, JPA и Flyway; пустая первая миграция применяется
      при старте.
- [x] **0.3** Создать `frontend/` на Next.js + TypeScript + Tailwind; стартовая
      страница «Добро пожаловать в AgentClinic».
- [x] **0.4** Фронтенд вызывает `/api/health` и показывает статус бэкенда.
- [x] **0.5** Подключить shadcn/ui, общий layout (шапка, навигация, футер).
- [x] **0.6** Настроить тесты: JUnit, Vitest, один smoke-тест на Playwright.
