# Фаза 0. Скелет — валидация

Ветку `feature/phase-0-skeleton` можно вливать, только когда выполнены **все** пункты
ниже. Каждый пункт проверяется фактическим запуском, а не «должно работать».

## 1. Автоматические проверки (GitHub Actions, все jobs зелёные)

| Job | Команды | Что доказывает |
|-----|---------|----------------|
| `backend` | `./mvnw verify` | Код компилируется; MockMvc-тест health и тест миграции Flyway проходят. |
| `frontend` | `npm ci` → `npm run lint` → `npm run format:check` → `npm test` → `npm run build` | ESLint и Prettier без ошибок; Vitest-тесты (страница, `BackendStatus`, layout) проходят; production-сборка и проверка типов успешны. |
| `e2e` | `npx playwright install --with-deps chromium` → `npm run test:e2e` | Smoke-тест поднимает настоящий бэкенд и фронтенд и видит всю цепочку. |

Условие: CI запущен на последнем коммите PR, ни один тест не пропущен (`skip`/`only`).

## 2. Обязательное содержимое тестов

- **Backend, health:** `GET /api/health` → `200`, `Content-Type: application/json`,
  тело `{"status":"ok"}`.
- **Backend, Flyway:** в `flyway_schema_history` есть версия `1` с `success = true`;
  тест использует временную БД, а не `backend/data/`.
- **Frontend, `BackendStatus`:** три состояния — загрузка, «ok», «недоступен»
  (сетевая ошибка или не-2xx ответ).
- **Frontend, layout:** шапка, навигация и футер присутствуют.
- **E2E smoke:** на `/` видны «Добро пожаловать в AgentClinic», шапка и статус
  бэкенда «ok», полученный от реально запущенного Spring Boot (без моков).

## 3. Ручной чек-лист (перед слиянием)

- [ ] Свежий клон, выполняем команды из `README.md` в двух терминалах — оба
      приложения стартуют без ошибок (проверить на Windows — основная машина
      разработки).
- [ ] `http://localhost:3000` в браузере: заголовок, шапка с навигацией, футер,
      статус бэкенда «ok».
- [ ] Бэкенд остановлен → статус «недоступен», страница не ломается и нет
      необработанных ошибок в консоли.
- [ ] DevTools, ширина 375 px и 1280 px: layout не разваливается, горизонтального
      скролла нет.
- [ ] После первого старта существует `backend/data/agentclinic.db`, а `git status`
      его не показывает (как и `target/`, `node_modules/`, `.next/`).
- [ ] `curl http://localhost:8080/api/health` → `{"status":"ok"}`.

- [ ] `README.md` описывает требования, запуск и все тестовые команды.
- [ ] `specs/tech-stack.md` отражает Spring Boot 4, Node 24, npm и прокси `/api`.
- [ ] Этапы 0.1–0.6 отмечены в `specs/roadmap.md`.

      проходит свои проверки.
- [ ] В корне больше нет старого `src/` и `pom.xml`, а в репозиторий не попали
